# WebStudio

This is a practice project for a modern "WebStudio" landing page. The website includes a main page showcasing features, team members, and client logos, as well as a portfolio page with category filtering.

## Technologies
* **HTML5**
* **CSS3** (utilizing Flexbox and CSS variables for maintainability)
* **SVG Sprites** for scalable icons

## Project Structure
* `index.html` — The main landing page featuring business solutions, services, team information, and a client section.
* `portfolio.html` — The portfolio page showcasing various projects with filtering capabilities.
* `/css` — Modular stylesheets organized by component (common, header, main-page, footer, portfolio, clients, social).

## Key Features
* Responsive layout structure.
* Typography integration using Google Fonts (Roboto and Raleway).
* Consistent styling with `modern-normalize`.
* Social media integration and interactive client logos.
