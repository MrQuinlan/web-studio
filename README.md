# WebStudio

Engineering-focused landing page for a web studio. The project prioritizes reliability, modularity, and understanding of core web mechanics.

## Technical Approach
* **Architecture**: Component-based CSS structure with modular files.
* **Resilience**: Inline SVG implementation to ensure icon stability regardless of stylesheet status.
* **Layout**: Desktop-first methodology using Flexbox, prioritizing structural integrity.
* **Interaction**: Minimal, vanilla JavaScript implementation to handle UI components (modals, form state).

## Structure
* `index.html` / `portfolio.html`: Semantic markup core.
* `/css`: Modular styles covering layout, header, footer, and individual components.
* `/js`: Lightweight scripts for interactivity.
* `/images`: Assets and SVG sprites.
